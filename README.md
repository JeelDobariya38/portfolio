# Jeel Dobariya — Portfolio

A responsive, dark-first personal portfolio built with HTML, CSS, and vanilla JavaScript.

## Run locally
Open `index.html` in a browser. For the most reliable local experience, serve this folder with any static file server.

## Deploy
Upload the contents of this folder to GitHub Pages, Netlify, Vercel static hosting, or any static web host.

## Customize
- `js/projects.js`: add or edit project cards.
- `index.html`: update bio, education, and contact details.
- `css/styles.css`: adjust colors, typography, spacing, and responsive layouts.

## Notes
- Dark mode is the default. Theme preference is saved in local storage.
- Icons and fonts load from CDNs, so an internet connection is needed for those assets.
- The portfolio intentionally does not include invented GitHub statistics or unverified academic details.
