01 / ABOUT

Curious by nature.
Builder by choice.

I enjoy taking ideas from a rough concept to a working product — learning the details, solving the tricky parts, and making the result useful.

My work sits at the intersection of application development, backend engineering, and open-source software.

I like exploring how software works beneath the surface: how data is structured, how features fit together, and how code can stay understandable as a project grows. I learn by building, iterating, and sharing what I make.
